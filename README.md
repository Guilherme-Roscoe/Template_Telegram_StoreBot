# Template_Telegram_StoreBot
## ✅ Pré-requisitos:
Crie um bot no Telegram usando o BotFather e pegue o Token do Bot. 

Instale a biblioteca python-telegram-bot: ```pip install python-telegram-bot --upgrade```

## ▶️ Como executar:
Substitua 'YOUR_BOT_TOKEN_HERE' pelo token do seu bot.

Execute com:
```python bot.py```
